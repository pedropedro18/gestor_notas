# Titanic - Previsão de Sobrevivência

Projeto de treino com rede neural (Keras/TensorFlow) para prever
se um passageiro do Titanic sobreviveu, com base em idade, sexo,
classe da viagem e outros dados.

## Resultado
Acurácia no teste: ~8.12%

## Como correr

1. Ativar o ambiente virtual:
   venv\Scripts\activate

2. Instalar as bibliotecas necessárias:
   pip install -r requirements.txt

3. Correr o programa:
   python teste.py

## Ficheiros
- teste.py -> código principal
- titanic_data/ -> dados usados no treino
